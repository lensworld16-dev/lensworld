# LENS S WORLD - Luxury & Prescription Eyewear Store

A modern, responsive e-commerce web application for prescription eyeglasses, sunglasses, and custom lenses.

## Features
- **Prescription Lens Guide**: Anti-Glare, Blue Cut, Photochromic, and Progressive lenses.
- **Doctor Slip Upload**: Direct camera / photo prescription slip upload.
- **Live Cart & Wishlist**: Persistent state with in-cart coupon application.
- **Admin Dashboard**: Real-time order tracking, product management, and gallery banner photo uploads.
- **Instant Email Alerts**: EmailJS integration for order confirmations.
- **WhatsApp Integration**: 1-click customer chat and invoice sharing.

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript / Vite
- Supabase (Backend/Database)
- EmailJS (Order Confirmations)
